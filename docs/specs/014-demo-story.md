# Repeatable demo and engineering story

Status: recruiter-facing README, deterministic UI captures, walkthrough, and
short-form video storyboard delivered 2026-11-18. The longer multi-scene recording
and optional engineering post remain out of scope.

## Acceptance

- A deterministic original-facility walkthrough: brief, manual drone with AUTOfleet,
  one scan/evidence update, handoff, replay, debrief and measured policy comparison.
- Provide one easy documented command/preset and a repeatable ordered interaction
  script; distinguish deterministic core commands from variable wall-clock autoplay.
- Produce readable screenshot artifacts and a35-45second recording storyboard with
  large terminal text and short captions; keep media generated from actual app state.
- README explains purpose, architecture, run commands and evidence without implying
  physical sensing, real drones, confirmed discoveries or universal planner wins.
- Draft a blog/X thread using actual multi-agent engineering findings: roles/file
  ownership, a caught bug, regression evidence, human decisions and remaining limits.
  Explicitly distinguish coding agents from simulated search drones.
- No fabricated recruiter impact, speedups, accuracy or benchmark numbers. Optional
  recording tooling stays outside app dependencies; adding/installing a new tool
  or publishing to social accounts requires the applicable explicit authorization.

## Delivered

- The README leads with the hidden-beacon mission and a real animated UI capture.
- [The demo guide](../DEMO.md) records the 132 × 55 viewport, mission settings, seed,
  and ordered interaction sequence for the full candidate-to-verification story.
- The replacement capture shows a deterministic mission through confirmation.
  Drone colors, path ownership, candidate, and verified markers are legible.
- The screen and guide state that readings and targets are simulated. The video is
  generated from actual Textual app states and never reads the hidden objective to
  choose its route.

The optional engineering post may be developed separately. No social account was
used and no external content was published.
